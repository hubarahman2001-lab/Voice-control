# 🎤 Voice Runner

A voice-controlled runner game. Dodge obstacles using your voice, right in the browser. No install needed.

**▶ Play it here:** https://hubarahman2001-lab.github.io/Voice-control/voice-runner.html

## How to play

- Open the link in **Chrome** and press **Start**.
- Allow the microphone when asked.
- Say **"jump"** to jump over cactuses.
- Say **"duck"** to duck under birds.
- A loud shout or clap also makes you jump (instant).
- After game over, say **"start"** to play again.

Keyboard / tap also works for testing: **Space** or **Up arrow** = jump, **Down arrow** = duck.

## Run it locally

Download `voice-runner.html` and open it in Chrome. That's it.

## Notes

- Voice recognition uses the browser's built-in Web Speech API, so Chrome works best.
- Your best score is saved in your browser.
